# Sri Lanka Flood Early-Warning Benchmark

## Overview
This repository implements a terrain-aware multimodal flood GNN for the Kelani river basin, Sri Lanka.

## Dataset Freeze (Phase C)
The dataset used in this project has been frozen.
- **Tabular Data (`data/processed/`)**: Contains the core panel data from 2024. `flood_dataset.parquet` contains 410,931 rows.
- **Image Data (`data/sar_chips/`)**: Contains the SAR image chips. Note that 9 incompatible 256x256 SAR frames have been excluded.
